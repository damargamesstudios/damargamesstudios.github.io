# DaMar Games Studios website

Production-ready static website for GitHub Pages.

## Publish

1. Create a public GitHub repository named exactly `damargamesstudios.github.io`.
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch **main**, folder **/(root)**.
5. After deployment, verify:
   - https://damargamesstudios.github.io/
   - https://damargamesstudios.github.io/app-ads.txt
